Cubyard Drive Backup

What it is

Cubyard is a self-hosted panel for selling and managing virtual servers. Each panel runs on its operator's own server and backs itself up regularly. Every backup is encrypted on that server before it leaves it.

Cubyard Drive Backup is the app a panel uses to keep a copy of those encrypted backups in the operator's own Google Drive or OneDrive, so the panel can be restored even if its server is lost.

How it works

  • In the panel, the operator chooses Google Drive or OneDrive, types a folder name and clicks Authorize. The panel shows a short code; the operator enters it on Google's or Microsoft's sign-in page on any device and allows access.
  • The panel creates that folder and uploads each new backup there. It deletes the old backups it uploaded itself, following the operator's retention settings.
  • Access stays within the backup folder. On Google Drive the app can only see files and folders it created (drive.file); on OneDrive it can only use its own folder under Apps (Files.ReadWrite.AppFolder).
  • The operator can revoke access at any time from their Google or Microsoft account.

Your data

Backups and authorization tokens travel only between the operator's own panel and the operator's own drive. The Cubyard project runs no service that receives them. See the privacy policy.

这是什么

Cubyard 是经营者自行部署的 VPS 销售和管理面板，运行在经营者自己的服务器上，并定期备份自身；每份备份在离开服务器之前就已加密。

Cubyard Drive Backup 是面板用来把这些已加密的备份另存一份到经营者自己的 Google Drive 或 OneDrive 的应用，这样即使服务器整体损毁，也能恢复面板。

怎样使用

  • 在面板中选择 Google Drive 或 OneDrive，填写文件夹名称，点击授权。面板显示一串代码，经营者在任意设备上打开谷歌或微软的登录页面，输入代码并同意。
  • 面板创建该文件夹，每次备份后上传一份，并按经营者的保留设置删除自己上传的旧备份。
  • 权限只到备份文件夹：在 Google Drive 中只能看到应用自己建的文件和文件夹（drive.file）；在 OneDrive 中只能使用“应用”下属于它自己的文件夹（Files.ReadWrite.AppFolder）。
  • 经营者可以随时在谷歌或微软账号中撤销授权。

您的数据

备份和授权令牌只在经营者自己的面板和网盘之间传递，Cubyard 项目没有任何接收这些数据的服务。详见隐私权政策。
